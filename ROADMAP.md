# Roadmap

Start is building toward the shortest trustworthy path from a stack decision to an agent-ready application.

## Now

- Keep every generated workspace deterministic and safe to rerun from a reviewed blueprint.
- Publish tested recipes for common application shapes.
- Improve error messages and recovery around package-manager and provider setup.
- Expand generated-workspace tests across supported option combinations.

## Next

- Add blueprint diffing so teams can review stack changes before regenerating.
- Add recipe validation in CI against current framework and provider versions.
- Provide optional provider setup checks without collecting credentials.
- Make generated agent workflows easier to customize without forking Start.

## Later

- Team-owned recipe registries.
- Blueprint policy checks for organization standards.
- Upgrade guidance for existing Start workspaces.

The order is intentionally flexible. Open a [feedback issue](https://github.com/bishoymly/start/issues/new?template=feedback.yml) with the problem you are trying to solve; concrete workflows influence the roadmap more than feature voting.
