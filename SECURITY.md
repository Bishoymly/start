# Security policy

## Supported version

Security fixes are applied to the latest published version of `@bishoymly/start`.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository, or email the address listed at [bishoy.io](https://bishoy.io).

Include the affected version, reproduction steps, impact, and any suggested mitigation. You can expect an acknowledgement within five business days.
